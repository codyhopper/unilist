Unicode Copy Shelf

Browse useful Unicode characters, find a symbol, and copy it with one click. Everything is generated locally—no downloads or network requests.

Search by character, hexadecimal code point, block, or a bundled name. Code point searches match exactly. A single space finds U+0020.

    Fonts matter: some glyphs depend on your installed fonts and operating system. An empty box may mean that your font does not support the character. Emoji appearance varies between platforms.

    Names and coverage: this app includes a small, bundled table of official Unicode names, not the complete Unicode database. “Unnamed code point” means no name is bundled; it does not necessarily mean the code point is unassigned. Some block positions may be unassigned.

    C0/C1 controls, surrogates, and Unicode noncharacters are omitted. Whitespace and known invisible formatting characters have descriptive previews; Copy still copies the actual character.

    Clipboard permissions vary by browser. If both copy methods are blocked, the app reports a failure instead of claiming success.
